# 『Wiresharkで読むパケット』演習用パケットファイル

書籍 **『Wiresharkで読むパケット ― 何から見るかが分かる』**（遠藤　暁）で開く、**著者が自分の環境で取得したパケットファイル**です。

本文に出てくる数値は、すべてこのファイルから実測したものです。手元に同じファイルを置いて、本を読みながら同じ画面を出してください。

> 繁體中文版的 README 在 [README_tw.md](README_tw.md)。

| ファイル | 章 | 中身 | パケット数 | サイズ | 期間 |
|---|---|---|---:|---:|---|
| `packets/http.pcapng` | 第1章 | テスト用 Web サーバーへ `curl` で1回アクセス | 24 | 2 kB | 16秒 |
| `packets/nmap.pcapng` | 第1章 | `nmap` の SYN スキャン（open / closed / filtered） | 1,991 | 148 kB | 8秒 |

ファイルが揃っているかは `capinfos` で確認できます。上の表のパケット数と一致するはずです。

```
capinfos -c packets/*.pcapng
```

## どうやって取ったか

MacBookAir の上で VMware Fusion Pro を動かし、その中に仮想マシンを2台置いているだけです。特別な機材は使っていません。

```
VM-WIN (172.16.28.158)  --HTTP :8000-->  VM-KALI (172.16.28.81)
   curl                                    python3 -m http.server 8000
                                           nmap / tcpdump
                                              |
                                              +--> MacBookAir (172.16.28.1)
                                                   Wireshark で解析
```

Kali 側でターミナルを3枚開き、**サーバー役**（`python3 -m http.server 8000`）・**操作役**（`nmap`、`ping`、`nslookup`）・**記録役**（`sudo tcpdump -nn -i eth0 -w ファイル名`）に分けています。

**同じ環境は誰でも作れます。**書籍の付録C に、構成・コマンド・読み替え方を全部書きました。**自分で取った記録のほうが学べます** ― 何をしたか自分が知っているので、画面に出たものが「予想どおり」なのか「予想外」なのかを判定できるからです。

## 扱うときの注意

- **名前解決は切って開いてください。** Wireshark の `View > Name Resolution` で *Resolve Network Addresses* を OFF。解析中に自分の PC が DNS を引きに行くのを防ぎます。
- **表示される時刻は、開いた PC のタイムゾーンです。** ファイルに記録されているのは UTC 基準の値です。日付がずれることもあります。時刻を記録に残すときは、どのタイムゾーンの値かを必ず添えてください。
- **IP アドレス・ポート・時刻は著者の環境の値です。** 自分で同じコマンドを実行すれば別の値になります。見るべきは値そのものではなく、パケットの並び方と構造です。
- **`notepad.pcapng` から取り出せる `notepad.exe` は、Windows 標準のメモ帳です。**マルウェアではありません。第5章は「pcap から実行ファイルを復元する」手順を練習する章ですが、手順は検体でもメモ帳でも1バイトも変わらないので、無害なバイナリで代用しています。
- `.pcapng` という名前ですが、`tcpdump -w` で取った4本は**中身はクラシック pcap 形式**です（`capinfos -t` で分かります）。Wireshark でも tshark でもそのまま開けます。書籍ではこれを「拡張子はファイルの中身を保証しない」の実例として扱っています。

## 本書について

『Wiresharkで読むパケット ― 何から見るかが分かる』は、**「パケットを開いたはいいが、何から見ればよいか分からない」**という状態を抜けるための本です。

- 第1章　パケットを覗く ― レイヤーと Wireshark
- 第2章　統計で全体像をつかむ ― 大きな pcap の歩き方
- 第3章　深く掘る ― 進んだ使い方
- 第4章　tcpdump / tshark 実務リファレンス
- 第5章　ファイルを復元する ― 1本の HTTP 転送を最後まで追う
- 付録A 演習用パケットファイル／付録B 用語ミニ辞典／付録C 著者の実験環境
